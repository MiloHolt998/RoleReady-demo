# RoleReady demo

Watch the demo at **https://miloholt998.github.io/RoleReady-demo/**.

This public repository contains the presentation video, a simple video player, the current placeholder logo, its poster, the Nunito heading font and a QR code. Application source is maintained separately in the private CityTwin-AI repository.

- `Demo.mp4`: the supplied 3-minute 36-second recording, remuxed without re-encoding for progressive playback.
- `RoleReady-demo-QR.png`: high-resolution QR image for slides and printing.
- `RoleReady-demo-QR.svg`: scalable QR image.
- `index.html`: responsive player with native sound, seeking and fullscreen controls.

The source recording is preserved separately. Publishing does not change its video or audio streams.

GitHub Pages serves this repository's `main` branch root. To update the film, replace `Demo.mp4` and push to `main`; the page URL and QR code stay the same.
